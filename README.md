# Datasets

This directory contains all datasets used across the six Deep Learning programming assignments.

Datasets are maintained centrally to avoid duplication across assignment directories.

| Dataset | File | Used In |
|---|---|---|

## Dataset Details

- **Dataset 1:** Classification and regression datasets used for Perceptron and FCNN experiments.
- **Dataset 2:** Group-specific MNIST subset used for optimizer comparison and dimensionality reduction experiments.
- **Dataset 3:** MNIST subset and Caltech-101 subset used for convolutional neural network experiments.
- **Dataset 4:** Handwritten character dataset and Consonant-Vowel (CV) segment dataset used for RNN and LSTM experiments.
